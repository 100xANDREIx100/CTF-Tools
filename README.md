# 🛠️ CTF-Tools

A personal repository of custom scripts, automations, and utilities built to speed up Capture The Flag (CTF) workflows. 

As I encounter repetitive tasks or complex math during challenges I write modular tools to automate them. This repo serves as my evolving, go-to toolkit.

## 🧰 The Toolkit

Here is a list of the current tools in this repository. Each tool has its own folder with a dedicated `README.md` explaining how to use it.

| Tool | Category | Description |
| :--- | :--- | :--- |
| [`/offset-calculator`](./offset-calculator) | Binary Exploitation | Automates finding the memory offset between two functions in an ELF binary to bypass PIE. |
